# 🩺 MediSense AI

### AI-Powered Healthcare Diagnosis & Medical Report Analysis Assistant

MediSense AI is a full-stack AI-powered healthcare application designed to help users understand medical reports, assess disease risk, and receive personalized health recommendations.

The application combines Machine Learning, medical report extraction, AI-powered explanations, and an interactive healthcare assistant into a single platform.

> ⚠️ **Medical Disclaimer:** MediSense AI is an educational and decision-support application. Its predictions are generated by machine learning models and should not be considered a confirmed medical diagnosis. Users should consult a qualified healthcare professional for medical decisions.

## 🏥 Multiple Disease Prediction Modules

MediSense AI provides separate prediction modules for different health conditions:

- ❤️ Heart Disease Prediction
- 🩸 Diabetes Prediction
- 🫁 Liver Disease Prediction
- 🫘 Kidney Disease Prediction
- 🧪 Lipid Profile Analysis
- 🩺 Symptom-Based Disease Prediction

Each module uses its own model and feature configuration according to the corresponding dataset.

---

# 📄 Medical Report Analysis

Users can upload medical reports and MediSense AI automatically extracts relevant medical values.

### Supported formats

- PDF
- JPG
- PNG

The application:

1. Accepts the patient's personal information.
2. Allows the user to upload a medical report.
3. Extracts values from the report.
4. Automatically fills the corresponding medical parameters.
5. Uses default values when a value is unavailable.
6. Allows the user to manually correct or complete missing values.
7. Lets the user confirm that all values are correct.
8. Sends the finalized information to the machine learning model.
9. Generates the prediction and risk assessment.

This makes the system useful even when medical reports have missing or differently formatted information.

# 🤖 MediSense AI Assistant

MediSense includes an AI healthcare assistant that allows users to ask follow-up questions after receiving a prediction.

Users can ask questions about:

- Their prediction
- Medical report values
- Symptoms
- Risk factors
- Diet
- Exercise
- Lifestyle
- General health-related explanations

The chatbot receives the patient's prediction context and uses it when answering questions.
