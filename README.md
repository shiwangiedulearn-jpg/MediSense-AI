# 🩺 MediSense AI

## AI-Powered Healthcare Diagnosis & Medical Report Analysis Assistant

MediSense AI is a full-stack AI-powered healthcare application that helps users understand medical reports, assess disease risks, and receive personalized health recommendations.

The application combines Machine Learning, medical report extraction, and an AI-powered healthcare assistant into one platform.

> ⚠️ **Disclaimer:** MediSense AI is an educational and decision-support application. Its predictions are generated by machine learning models and should not be considered a confirmed medical diagnosis. Always consult a qualified healthcare professional for medical advice.

## ✨ Features

### 🏥 Disease Prediction

MediSense AI provides multiple healthcare modules:

- ❤️ Heart Disease Prediction
- 🩸 Diabetes Prediction
- 🫁 Liver Disease Prediction
- 🫘 Kidney Disease Prediction
- 🧪 Lipid Profile Analysis
- 🩺 Symptom-Based Disease Prediction

Each module uses its own machine learning model and feature configuration.

---

### 📄 Medical Report Analysis

Users can upload medical reports and the application automatically extracts relevant medical values.

The workflow is:

1. Enter personal details.
2. Upload a medical report.
3. Extract medical values automatically.
4. Fill missing values using default values.
5. Allow the user to correct or complete missing values.
6. Confirm that the displayed values are correct.
7. Generate the prediction.
8. Display risk assessment and recommendations.

Supported report formats include PDF and image-based reports where applicable.

---

### 🤖 MediSense AI Assistant

After receiving a prediction, users can ask questions to the MediSense AI assistant.

The assistant can answer questions about:

- Prediction results
- Medical values
- Symptoms
- Risk factors
- Diet
- Exercise
- Lifestyle
- General health explanations

The assistant uses the patient's prediction information as context when answering questions.
